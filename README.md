💰 Personal Finance Manager (个人理财管理系统)
🌟 项目简介
本项目是一个基于 C# WinForms 开发的桌面端个人财务管理系统。项目严格遵循 Service-Repository 经典三层架构设计，实现了账户管理、收支记录、预算控制和财务报表等核心功能，帮助用户清晰、高效地管理个人资产和资金流动。

✨ 核心功能
账户管理 (Account Management):

支持添加、编辑、删除多种类型账户（如现金、银行卡、投资账户）。
账户删除时，自动执行交易记录的级联删除，确保数据的完整性和一致性。
实时计算和更新账户的当前余额。

收支交易记录 (Transaction Logging):

详细记录收入和支出交易，与账户和分类精确关联。
核心联动: 每笔交易发生后，系统自动触发 BLL 逻辑，重新计算并更新关联账户的余额。
预算控制与预警 (Budgeting & Warning):
支持为特定月份、特定支出类别设置预算金额和预警阈值（如 80%）。
交易发生后，实时更新预算的实际支出金额，并提供超支预警报告。

财务报表与分析 (Reporting & Analysis):

提供收支趋势统计（折线图数据）和分类汇总统计（饼图/柱状图数据）。
支持计算平均每日支出等关键财务指标。
支持将统计报表数据导出为 CSV 文件，便于在 Excel 中二次分析。
